# Laura & Bump 💗

Our pregnancy site — one `index.html`, no build step. Host it with GitHub Pages (Settings → Pages → Deploy from branch → `main`).

Tabs: **Timeline** (2-week blocks, a look-ahead week slider, and a "Read the science" panel for every stage), **Food** (eat vs avoid), **Hospital** (private vs public), **Along the way** (our notes), **Learn** (books, podcasts, YouTube, websites, apps).

Editing: everything lives in the lists at the top of the `<script>` near the bottom of `index.html` — `TIMELINE`, `SCI` (the science panels), `SIZE` (baby's size by week), `EAT`, `AVOID`, `NOTES`, `CHECKLISTS`, `LEARN`. Set `DUE_DATE` there so "we're here" shows on every device.

General information only — always check with your GP, midwife or obstetrician.
